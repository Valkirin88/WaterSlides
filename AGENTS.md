# Unity workflow

- Before ending a work turn or stopping work, exit Unity Play Mode and verify that it has stopped. Do not leave the game running while waiting for the user.
- If the requested result remains incomplete, state the concrete remaining work. Continue authorized work without requiring the user to repeat “continue”.
- Compare visual changes against the user's supplied references in the running game before reporting them as finished.
- Do not rebuild the waterslide geometry unless the user explicitly authorizes it.
- Read ПРОГРЕСС.md before project work and keep its dated journal updated with changes, actual verification results, user decisions, and remaining work. Do not mark unverified visual work as finished.
